# Contributing to Sakuvo

Thanks for helping improve Sakuvo!

1. Fork this repository and create a branch for your changes.
2. Make a focused change and explain it in your pull request.
3. Never commit personal finance records, API tokens, signing keys, or keystores.
4. Test your changes on an Android device or emulator before submitting.
5. Note that the original v0.4.0-beta source archive does not yet include a complete Gradle project; reproducible build setup is welcome.

By contributing, you agree that your contributions may be distributed under this repository's MIT License.
